Solmar Bay is an original top-down open-world crime game: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the SBPD through five wanted levels, and run six story missions for the fixer Marina Solano. It has traffic, pedestrians, police chases, combat, a HUD with a live minimap, a start screen, a pause menu, and saving — all drawn and sounded by original code, with no assets from any commercial game.

## Run it

```sh
node serve.ts  # then open http://localhost:8080
```
