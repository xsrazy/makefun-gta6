Neon Harbor is a top-down 2D open-world crime game set in a sun-soaked coastal city. Drive and fight through 6 story missions with a police heat system and wanted stars, living traffic, pedestrians, on-foot and in-car combat, and a synth soundtrack.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.
